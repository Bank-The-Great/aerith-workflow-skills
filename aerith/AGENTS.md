# Project Creator contribution boundary

This directory is the adapted portable package. Upstream skills outside this
directory remain reference material, not installed dependencies. Read the root
PROJECT_MEMORY.md pointer before substantive changes; the canonical lessons are
in this directory's PROJECT_MEMORY.md. Keep vendor syntax in adapters;
do not copy private host settings, credential material or proprietary prompts.
Validate with `python -m unittest discover -s aerith/tests -v` from the repo root.
